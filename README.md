# PlastyAI

**PlastyAI** is a mobile app that helps users track and reduce their microplastic and plasticizer exposure from food. It uses on-device machine learning to identify foods, estimate plasticizer contamination, and provide actionable health tips and educational content.

---

##Disclaimer

Please note that estimates generated by PlastyAI are estimates due to the severe lack of data surrounding microplastics, therefore may not be 100% accurate. 

---

## Features

- **Scan Foods:** Take a photo of your food to estimate plasticizer exposure.
- **Weekly Bar Graph & Trends:** Visualize your exposure over time.
- **Personalized Health Tips:** Get actionable advice based on your scan history.
- **Contamination Sources:** Learn where plasticizers come from in the food supply.
- **Offline-First:** All data and ML inference run locally on your device.
- **No Account Needed:** Your data stays private, on your device.
- **Accurate Plasticizer Data:** Uses Nat Friedman's [Plasticlist](https://www.plasticlist.org/) to deliver plasticizer amounts in ng/serving for each food.

---

## How It Works

- **On-Device ML:** The app uses a TensorFlow Lite model trained on **302 foods**, combining the [Fruits360](https://www.kaggle.com/datasets/moltean/fruits) and [Food101](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/) datasets. This enables robust food recognition directly on your device, with no internet required for inference.
- **Plasticizer Mapping:** Each recognized food is mapped to a plasticizer contamination value (ng/serving) using data from Nat Friedman's Plasticlist, which aggregates published scientific measurements of plasticizer content in foods.
- **Exposure Tracking:** Your scans are stored locally and visualized as weekly bar graphs and trendlines, helping you monitor your exposure over time.
- **Health Tips & Education:** The app provides personalized health tips and educational content based on your scan history and exposure levels.

## Getting Started

```bash

# or
yarn install
```

### 2. **Run the App Locally**

#### **iOS**
```bash
npx expo start
# Then press 'i' to open in iOS simulator, or scan QR code with Expo Go app
```

#### **Android**
```bash
npx expo start
# Then press 'a' to open in Android emulator, or scan QR code with Expo Go app
```

### 3. **Build for Production**

- **iOS:** Use Xcode or EAS Build to create an .ipa for App Store submission.
- **Android:** Use Android Studio or EAS Build to create an .aab/.apk for Play Store.

## Deployment

### **Mobile App (Recommended)**
- **iOS:** Deploy via App Store (requires Apple Developer account)
- **Android:** Deploy via Google Play (requires Google Play Console account)

### **Backend API **
- The project includes a Flask API for server-based ML inference. This is useful if you want to:
  - Offload ML inference to a server (for older devices or more powerful models)
  - Integrate with other services or a web frontend
- **How it works:**
  - The Flask API receives a food image, runs the same TFLite model as the app, and returns the predicted food and plasticizer value.
  - Can be deployed to Railway, Vercel (as a serverless function), or any cloud provider.
- **Current version does NOT require a backend**—all ML runs on-device by default!

## FAQ

**Q: Do I need a backend or Railway?**  
A: No! The app is fully client-side. Railway was only needed for the original server-based ML approach.


**Q: How is my data stored?**  
A: All scan data is stored locally on your device using AsyncStorage.

**Q: Where does the plasticizer data come from?**  
A: plasticizer values are sourced from Nat Friedman's [Plasticlist](https://github.com/natfriedman/plasticlist), which aggregates published scientific measurements of plasticizer content in foods.

**Q: What foods can the app recognize?**  
A: The app is trained to recognize 302 foods, using a model built from the Fruits360 and Food101 datasets.
